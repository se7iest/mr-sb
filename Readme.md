A high-fidelity, frameless PyQt6 desktop application engineered for Discord channel broadcasting and group chat renaming. Features a custom neon-aesthetic UI, real-time telemetry, and multi-threaded execution.

## Features

- **Broadcast Protocol**: Multi-threaded message spammer targeting specific channel IDs.
- **Name Changer**: Automated Group Chat (GC) renaming with sequential suffixes.
- **Telemetry Dashboard**: Real-time stats for sent packets, faults (errors), and cycles. Includes sparkline graph rendering.
- **Custom UI Engine**: Frameless window, animated aurora backdrop, particle bursts, glassmorphism frames, and a boot sequence overlay.
- **Authentication**: Local password gate before application initialization.

## Prerequisites

- Python 3.9 or higher.
- Active Discord user token.
- Target Channel ID or Group Chat ID.
